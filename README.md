# Tirumala High School Website

Responsive React + Vite website for Tirumala High School (Nursery to Class 10, State Board).

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The production output is generated in `dist/`.

## Included pages

- Home
- About Us
- Academics
- Admissions
- Activities
- Gallery
- Notices
- Contact Us

## Before publishing

- Replace placeholder school phone number, email, and office timings with verified details.
- Replace sample notices with approved current notices.
- Admission and contact forms are currently front-end demonstrations and do not send or store submissions. Connect a secure backend or approved form service before collecting enquiries.
- Review all imagery and publish student photographs only with appropriate permission.
